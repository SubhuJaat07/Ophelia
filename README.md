## 📊 **Leveling & XP System**

### **How It Works**
- **Message XP**: Earn XP for every message (configurable)
- **Voice XP**: Earn XP for time spent in voice chat
- **Levels**: Automatic level-up with notifications
- **Badges**: Unlock achievements for milestones
- **Rank Titles**: Special titles based on level

### **XP Sources**
| Activity | XP Reward |
|----------|-----------|
| Sending message | +2-5 XP |
| Voice chat (per min) | +1 XP |
| First message of day | +10 XP |
| Winning games | +20-50 XP |
| Receiving reputation | +5 XP |

## 🔒 **Security Architecture**

Ophelia takes security seriously with enterprise-grade protections:

### **Authentication & Authorization**
| Feature | Implementation |
|---------|----------------|
| **Discord OAuth2** | Secure authentication via Passport.js |
| **Session Management** | HttpOnly, Secure, SameSite cookies with HMAC-SHA256 signing |
| **CSRF Protection** | Token validation on all state-changing operations |
| **Rate Limiting** | Per-IP limiting (10-100 req/min based on endpoint) |
| **Permission Checks** | Granular Discord permission validation |

### **Data Protection**
| Feature | Description |
|---------|-------------|
| **Input Sanitization** | All user inputs validated and escaped |
| **XSS Prevention** | Output encoding on all dynamic content (`escapeHTML()`) |
| **SQL Injection Protection** | Parameterized queries via Supabase |
| **PII Protection** | Sensitive data (birthdays, etc.) restricted by role |
| **Open Redirect Prevention** | Whitelist-based URL validation |

### **Infrastructure Security**
| Feature | Status |
|---------|--------|
| **HTTPS Only** | ✅ Enforced in production |
| **Host Validation** | ✅ Prevents header injection |
| **CORS Policies** | ✅ Properly configured |
| **Socket Authentication** | ✅ Session-verified connections (prevents identity spoofing) |
| **Secure Tokens** | ✅ Cryptographically secure tokens (`crypto.randomBytes`) |
| **Anti-Nuke** | ✅ Server protection enabled |

### **Privacy Commitment**
- No data sold to third parties
- Minimal data collection
- User data deletable on request
- GDPR compliant practices
- Transparent data usage
