## 🔒 **Enterprise-Grade Security**

Your server's safety is our priority:

- **🔐 Discord OAuth2 Authentication** – Secure login via Discord
- **🍪 Secure Sessions** – HttpOnly, SameSite cookies with HMAC-SHA256 signing
- **🛡️ CSRF Protection** – Token validation on all state-changing operations
- **🚦 Rate Limiting** – Per-IP limiting to prevent abuse
- **✅ Input Sanitization** – All inputs validated and escaped
- **🔒 XSS Prevention** – Output encoding on all dynamic content
- **🗄️ SQL Injection Protection** – Parameterized queries via Supabase
- **🔒 PII Protection** – Sensitive data restricted by role
- **🔗 Open Redirect Prevention** – Whitelist-based URL validation
- **🔐 Socket Authentication** – Session-verified connections (no identity spoofing!)
- **🔑 Secure Tokens** – Cryptographically secure tokens using crypto.randomBytes
- **🛡️ Anti-Nuke Protection** – Automatic raid detection and prevention
